## 🛟 Como usar

Quando seu resultado estiver diferente do esperado:

1. abra a pasta da etapa;
2. compare os nomes dos arquivos;
3. compare seu código;
4. faça uma mudança por vez;
5. teste novamente.

O objetivo é **encontrar a diferença**, não apagar tudo e começar de novo.
