# Etapa 00 — Preparação

## Objetivo

Criar a pasta do projeto, abrir no VS Code e reconhecer o Explorer, o editor e o terminal.

```bash
mkdir blog-tech
cd blog-tech
code .
```

Depois, crie o arquivo `index.html`.

## Antes de seguir

Confirme que você sabe:

- onde os arquivos do projeto aparecem no VS Code;
- como criar um novo arquivo;
- como salvar;
- como abrir o terminal integrado.
