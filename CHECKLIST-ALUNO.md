# Checklist do estudante

- [ ] Consegui abrir o projeto no VS Code.
- [ ] Sei localizar `index.html`, CSS e JavaScript.
- [ ] Alterei pelo menos um conteúdo.
- [ ] Usei `git status` para verificar mudanças.
- [ ] Criei um commit com mensagem objetiva.
- [ ] Enviei o commit com `git push`.
- [ ] Encontrei o commit no GitHub.
- [ ] Configurei o GitHub Pages para `main` + `/docs`.
- [ ] Abri o endereço público do site.
- [ ] Fiz uma segunda alteração e confirmei que a página publicada foi atualizada.
